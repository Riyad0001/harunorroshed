# MD. HARUN OR ROSHED - Professional Portfolio

A modern, responsive multi-page portfolio website showcasing my professional experience, skills, and projects as a Software Engineer specializing in Python and Backend development.

## Features

- **Multi-Page Design**: Three dedicated pages (Home, About, Projects) for better navigation and SEO
- **Responsive Design**: Built with Bootstrap 5 for optimal viewing on all devices
- **Modern UI**: Clean, professional layout with hover effects and smooth transitions
- **Interactive Elements**: Animated counters, smooth scrolling, and project filtering
- **Professional Content**: Comprehensive showcase of skills, experience, and achievements

## Technologies Used

- HTML5
- CSS3 with custom properties
- Bootstrap 5.3.0
- Font Awesome 6.0.0
- Google Fonts (Inter)
- Vanilla JavaScript

## How to View

1. Clone or download this repository
2. Open `index.html` in any modern web browser
3. Navigate between pages using the top navigation menu

## Pages Included

- **Home (index.html)**: Landing page with hero section, stats, featured skills, and project previews
- **About (about.html)**: Detailed about page with story, experience timeline, education, and achievements
- **Projects (projects.html)**: Dedicated projects showcase with filtering and detailed project cards

## Customization

To customize this portfolio for your own use:

1. Replace the content in each section with your own information
2. Update the contact links and social media profiles
3. Modify the color scheme in the `<style>` section if desired
4. Add your own images or additional sections as needed
